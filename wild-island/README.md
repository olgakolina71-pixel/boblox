# Дикий остров — Survival Online

Браузерная survival-демка на Three.js, опубликованная через Cloudflare Workers.

## Запуск
Откройте: https://wild-island-survival.olgakolina71.workers.dev

Для проверки мультиплеера откройте эту же ссылку в двух независимых браузерах или попросите друга зайти по ссылке. Оба клиента входят в комнату `island-main`.

## Сейчас реализовано
- 3D-остров с процедурными текстурами травы, песка, коры, листвы и камня.
- Вода, дневной/ночной цикл, тени и атмосферная дымка.
- WASD + мышь на компьютере; экранный джойстик на телефоне.
- Игроки видят друг друга в реальном времени через WebSocket и Cloudflare Durable Objects.
- Сервер назначает разные точки появления.
- Сбор ресурсов синхронизирован: один игрок забирает узел, остальные клиенты видят, что он исчез; список собранных узлов хранится в Durable Object.
- Здоровье, сытость, жажда, инвентарь и базовое ремесло.

## Ограничения текущей версии
Это первая сетевая версия: инвентарь, здоровье, день/ночь, крафт и построенные объекты пока локальны для каждого клиента. Нет аккаунтов, чата и сохранения персонажа. Игроки и общие узлы ресурсов синхронизируются в общей комнате.

## Технологии
- Three.js 0.160
- Cloudflare Workers
- Cloudflare Durable Objects (SQLite-backed namespace)
- CanvasTexture для процедурных материалов

Текстуры создаются в браузере процедурно; внешняя платная генерация Meshy не запускалась.
