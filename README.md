# BLOCKVERSE 2.0

Новая версия веб-платформы BLOCKVERSE.

## Запуск
Откройте `index.html` через локальный веб-сервер или опубликуйте репозиторий как статический сайт.

## Технологии
- HTML, CSS, JavaScript
- Babylon.js (CDN) для 3D-сцены
- Адаптивный интерфейс для компьютеров и телефонов

## Управление 3D-лобби
- WASD или стрелки — перемещение аватара
- Пробел — прыжок
- Перетаскивание сцены — вращение камеры

## Текущий статус
Это первый рабочий frontend-прототип. Навигация, адаптивная оболочка и 3D-лобби реализованы. Аккаунты, серверный мультиплеер, редактор сохранений и каталог пользовательских игр требуют следующих этапов разработки и серверной интеграции.


## BLOCKVERSE 2.0
Первый frontend-релиз: новый интерфейс, Babylon.js lobby и адаптивная навигация.
