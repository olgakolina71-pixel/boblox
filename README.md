# BLOCKVERSE 2.0

BLOCKVERSE — веб-платформа игровых миров на Babylon.js с серверным API Cloudflare Workers и Durable Objects.

## Публикация

- Frontend: Cloudflare Pages — https://blockverse-2.pages.dev
- Backend API: https://blockverse-api.olgakolina71.workers.dev
- Health: https://blockverse-api.olgakolina71.workers.dev/health

## Структура

- `index.html`, `styles.css`, `app.js` — клиентское приложение и 3D-лобби.
- `server/worker.js` — API, WebSocket-шлюз и Durable Object.
- `server/wrangler.toml` — конфигурация Worker и SQLite-backed Durable Objects.
- `wild-island/` — отдельный survival-проект, сохранён без изменений.

## Серверные возможности

- Анонимная серверная сессия с криптографически случайным ключом.
- Профиль игрока, имя и аватар сохраняются в Durable Objects.
- Каталог миров: три официальных мира и пользовательские миры.
- Создание миров с серверной валидацией.
- Редактор сетки: кубы, платформы, деревья и фонари; макет сохраняется на сервере.
- Комнаты реального времени через WebSocket: подключение, выход, синхронизация позиций игроков.
- Чат комнат с ограничением длины и частоты сообщений; история хранится на сервере.
- Список друзей с добавлением по ID аккаунта.
- Мобильный джойстик для перемещения в 3D-комнате.

## Сессии и безопасность

Первый запуск создаёт гостевой аккаунт. Случайный bearer-токен хранится в localStorage браузера, сервер хранит профиль отдельно от токена. Потеря локального токена означает потерю доступа к этой гостевой учётной записи: перенос между устройствами и восстановление через пароль пока не реализованы.

API проверяет входные данные, ограничивает длину сообщений и макетов, проверяет права владельца на редактирование миров и ограничивает частоту перемещения/сообщений в комнате. Не публикуйте токен сессии.

## Запуск локально

Откройте корневую папку через локальный статический сервер. Для backend используйте Cloudflare Workers и конфигурацию `server/wrangler.toml`. В клиентском `app.js` API URL указывает на опубликованный Worker.

## Границы текущего релиза

Мультиплеер, серверные профили, каталог миров, создание миров, чат и сохранение макетов работают как серверные функции. Физика, столкновения, игровой прогресс и полноценная логика режимов Adventure/Obby/Survival ещё требуют отдельных игровых систем. Платёжная система и восстановление аккаунта не входят в этот релиз.
